# Railway Rail Wear Calculator

Flutter/Android project for recording rail wear measurements and calculating permissible rail wear/reprofiling once the controlled UK railway limits are verified.

## Current prototype
- Dark, field-friendly interface
- Rail type selection
- Vertical wear and side wear inputs
- Pre-1979 rail ultrasonic-test warning
- Think Atlas branding
- Safety-critical calculation deliberately disabled until verified limits are entered

## Planned
- Verified UK rail types and minimum rail-depth limits
- Rule-of-9 calculation
- Maximum permissible reprofiling/grinding result
- UK Track ID section
- Defect guidance
- Offline operation

> Prototype only. Do not use for operational railway safety decisions until the calculation data has been verified against the applicable controlled standard.
